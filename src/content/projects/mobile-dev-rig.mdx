## Overview

I built a mobile dev rig so I can steer production codebases from my phone — no keyboard involved. It repurposes my laptop as a personal headless cloud: OpenCode runs on the Mac, Tailscale tunnels it to my phone, and a mobile browser renders the live app with hot reload.

## The Architecture

- **Brain (Mac):** the dev server, filesystem, and OpenCode agent
- **Network (Tailscale):** a private WireGuard mesh that gives the phone a stable tailnet IP
- **Interface (phone):** Termius for the terminal, a mobile browser for the live preview

## The Build

- Bound the dev server to all interfaces with `next dev --hostname 0.0.0.0`
- Wired `allowedDevOrigins` into `next.config.ts` so cross-origin HMR from the tailnet IP works
- Runs inside `tmux` so sessions survive phone Wi-Fi → 5G handoffs

## The Workflow

Two tabs: prompt OpenCode in Termius ("create a responsive hero with a frosted-glass effect"), watch it write to the Mac's SSD, and see the page update in the mobile browser the moment the file saves.
